# Paradise Nursery Shopping Application
# A Simple Project to Learn React!

Welcome to **Paradise Nursery** — your friendly online plant shop! This is a full-featured React shopping application where users can browse houseplants, add them to a shopping cart, and manage their orders.

## About the Project

Paradise Nursery is a  React-based "e-commerce" application built with **Vite**, **React**, **Redux Toolkit**, and **React Router**. The app lets plant lovers explore a wide variety of houseplants organized by category, add their favorites to a shopping cart, and view a detailed cart summary before checkout.

## Features

- **Landing Page** with a beautiful background image and a "Get Started" button
-  **Product Listing Page** with multiple plant categories
  - At least 3 plant categories
  - At least 6 unique houseplants per category
  - Each plant shows a thumbnail, name, and price
  - "Add to Cart" button that disables after adding
-  **Shopping Cart Page**
  - Shows total cart amount
  - Shows total cost for each plant
  - Increase / decrease quantity buttons
  - Delete button to remove items
  - Checkout button (shows "Coming Soon")
  - Continue shopping button
- **Navigation Bar** with links to Home, Plants, and Cart (with a dynamic cart count badge)

## 🛠️ Technologies Used

| Tool | Purpose |
|------|---------|
| **React 19** | Building the user interface |
| **Vite** | Fast development & build tool |
| **Redux Toolkit** | Managing the shopping cart state globally |
| **React Router** | Navigating between pages |
| **CSS3** | Styling the application |

## 🚀 How to Run the Project

### Prerequisites
Make sure you have **Node.js** (version 18 or higher) installed on your computer.

### Installation
1. Open a terminal in the project folder.
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and visit the URL shown in the terminal (usually `http://localhost:5173`).

### Build for Production
```bash
npm run build
```
